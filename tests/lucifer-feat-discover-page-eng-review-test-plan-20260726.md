# Test Plan — Onboarding Flow
Generated by /plan-eng-review on 2026-07-26

## Affected Pages/Routes
- `/_authenticated` — beforeLoad now checks `onboarding_completed` flag, redirects to `/onboarding` if not done
- `/onboarding?step=1` — Artist selection page
- `/onboarding?step=2` — Song heard-tagging
- `/onboarding?step=3` — City/location

## Key Interactions to Verify
- New user signs up → redirected to /onboarding?step=1 (never sees /home)
- Returning user (onboarding_completed=true) → goes directly to /home
- Select 3 artists on step 1 → "Continue" button enables → step 2 loads songs
- Tap Heard on step 2 → toggle fills green, tap again → unfills
- Step 3 "Save" → updates profile, sets onboarding_completed=true, redirects to /home
- Step 3 "Skip" → sets onboarding_completed=true, redirects to /home

## Edge Cases
- Artist with < 10 songs: should not appear in selection list
- Artist with 0 songs: filtered out by song count threshold
- User refreshes on step 2: artist selections lost (sessionStorage), back to step 1
- Supabase unreachable on step 1: error state shown, retry button
- Network error on Heard toggle: toast, optimistic revert
- Auth guard: hit /home directly as new user → redirect to /onboarding

## Critical Paths
- Full flow: sign up → pick 3 artists → tag songs as heard → skip city → land on /home
- Auth guard: hit /home directly as new user → redirect to /onboarding
