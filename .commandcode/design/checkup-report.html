Key Findings

Body text 14px — below 16px minimum

EntryCard, DiaryCard, ReviewComposer, ReviewList, and others use text-sm (14px) for reading body text. Stat labels and BottomNav use text-[10px] — near-illegible. All body reading text should be at least text-base (16px).

Missing aria-labels on icon-only buttons

Like (Heart), Dislike (ThumbsDown), and Pagination prev/next buttons have no aria-label. Screen reader users hear nothing. Also: empty alt="" on avatar and album art images — these convey identity and song context.

Images lack CLS-prevention attributes

Zero instances of width/height on <img> tags. No loading="lazy" except one search result. No decoding="async". Every album art, avatar, and thumbnail load causes layout shift.

Touch targets below 44px

Pagination (40px), LikeDislike (~36px), Heard/Want (~36px), genre filter chips (~28px) all fall below the 44px minimum for comfortable touch interaction.

Opacity-reduced text fails contrast

text-muted-foreground/60 at ~3.8:1 fails WCAG AA 4.5:1. Stat labels at 10px + 40% opacity doubly fail.

Skipped heading level in DiscoverPage

DiscoverPage.tsx uses only <h3> with no <h2> parent — heading hierarchy skips a level.

Prescriptions

1. /design typeset — Bump body reading text from text-sm (14px) to text-base (16px). Fix heading hierarchy in DiscoverPage.
2. /design interaction — Add aria-label to icon-only buttons (Like, Dislike, Pagination). Add descriptive alt text to avatar and album art images.
3. /design finish — Add width/height attributes, loading="lazy", and decoding="async" to all <img> tags.
4. /design responsive — Increase touch targets to 44px minimum for Pagination, LikeDislike, Heard/Want, genre chips.
5. /design recolor — Adjust text-muted-foreground opacity values so reduced-opacity text meets 4.5:1 contrast.

The design foundation is strong — authored identity, excellent state handling. These Watch scores are targeted fixes, not structural redesign.
